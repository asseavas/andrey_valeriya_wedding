# Wedding Invitation

A mobile-first wedding invitation website built with plain HTML, CSS, and JavaScript — no frameworks or build tools.

- Animated envelope opening screen
- Background music with a play/pause toggle
- Sections for the invitation, event calendar, and venue details

You can view it here: [Invitation](https://asseavas.github.io/andrey_valeriya_wedding)
